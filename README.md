# 42 School Projects

This repository contains a collection of projects completed as part of the 42 school curriculum. Each project is designed to teach a specific set of skills, from basic C programming to more complex topics like web servers and operating systems.

## Projects

Below is a list of the projects included in this repository. Each project has its own directory and a more detailed README file with instructions on how to compile and run the code.

*   **[Born2beroot](Born2beroot/)**: This project is about setting up a virtual machine and a web server.
*   **[CPP Modules](CPP/)**: A series of modules to learn the C++ programming language.
*   **[Inception](Inception/)**: This project involves setting up a web server with multiple services using Docker.
*   **[Libft](Libft/)**: A custom C library with implementations of many standard C functions.
*   **[NetPractice](NetPractice/)**: A series of exercises to learn about computer networks.
*   **[Philosophers](Philosophers/)**: A classic concurrency problem to be solved using threads and mutexes.
*   **[cub3d](cub3d/)**: A project to create a 3D game engine using raycasting, similar to Wolfenstein 3D.
*   **[fract-ol](fract-ol/)**: A project to create a fractal explorer, allowing users to explore different fractal sets like Mandelbrot and Julia.
*   **[ft\_printf](ft_printf/)**: A custom implementation of the C `printf` function.
*   **[get\_next\_line](get_next_line/)**: A function that reads a file line by line.
*   **[minishell](minishell/)**: A project to create a simple shell, similar to bash.
*   **[pipex](pipex/)**: A project to learn about pipes and redirections in a shell.
*   **[push\_swap](push_swap/)**: A project to sort a stack of numbers using a limited set of operations.
